# Mozvane — combat sandbox (prototype)

Play: https://raw.githack.com/EricMoz/mozvane-impound-prototype/main/index.html

- `index.html` — combat sandbox (movement, attacks, dash, eye beam). Desktop + phone (landscape).
- `old-level.html` — the earlier stealth/impound level.

Desktop: WASD move · Click / J attack (3-hit combo) · Space / Shift dash · hold Right-click / K to aim the beam, release to fire (when Zafus is full).
Phone: left thumb joystick · ATTACK (big) · DASH · BEAM (auto-targets).

See CREDITS.md for third-party assets (stand-in character is CC0, Quaternius).
